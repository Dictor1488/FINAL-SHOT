# INQ Final Shot

Мод для **World of Tanks от Wargaming**, который после уничтожения машины показывает последние полученные попадания и выделяет смертельный выстрел.

## Состояние проекта

Версия `0.1.0` — первый тестовый MVP. В ней реализованы:

- сбор последних попаданий по машине игрока;
- название машины и ник стрелявшего;
- урон, тип и признак премиум-снаряда;
- определение смертельного попадания;
- отдельная боевая панель на ActionScript 3;
- перетаскивание панели мышью и сохранение позиции;
- локализации RU, UK и EN;
- автоматическая сборка `.wotmod` через GitHub Actions.

В этой версии **ещё нет 3D-модели танка и точек попаданий**. Это следующий этап после проверки сбора событий на актуальном клиенте.

## Установка тестовой сборки

1. Откройте вкладку **Actions** в репозитории.
2. Запустите workflow `Build INQ Final Shot` и укажите версию, например `0.1.0`.
3. Скачайте artifact с готовым `.wotmod`.
4. Поместите файл в:

```text
World_of_Tanks/mods/<текущая_версия_игры>/
```

## Настройки

После первого запуска создаётся файл:

```text
World_of_Tanks/mods/configs/inq/final_shot/final_shot.json
```

Пример:

```json
{
  "enabled": true,
  "maxHits": 3,
  "displaySeconds": 20.0,
  "position": [-1, 145],
  "scale": 1.0,
  "showPlayerName": true
}
```

`position[0] = -1` автоматически центрирует панель по горизонтали. Панель также можно перетащить мышью — новая позиция сохранится автоматически.

## Отладка

Создайте пустой файл `.debug_mods` в корне клиента. После этого подробные сообщения мода будут попадать в `python.log` под именем `inq.final_shot`.
